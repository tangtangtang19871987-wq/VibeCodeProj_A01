# Array Generator

A Python module for generating synthetic periodic arrays of target features (contacts, vias) for testing and validation of SRAF consistency checking algorithms.

## Features

- **Perfect Periodic Arrays**: Generate M×N arrays by tiling unit cells
- **Flexible Unit Cells**: Support arbitrary polygons with multiple features per cell
- **Pre-defined Templates**: Simple, staggered, and cluster contact arrays
- **Multiple Export Formats**: GDS, CSV, space-separated text
- **Visualization**: Plot unit cells and arrays with matplotlib
- **Type-Safe**: Full type hints throughout
- **Well-Tested**: >90% test coverage

## Quick Start

### Simple Contact Array

```python
from array_generator import simple_contact_array, export_to_gds, plot_array

# Create a 10×10 array of 50nm square contacts with 100nm pitch
array = simple_contact_array(cd=50.0, pitch=100.0, rows=10, cols=10)

# Export to GDS
export_to_gds(array, 'contacts.gds', layer=1)

# Visualize
plot_array(array)
```

### Custom Unit Cell

```python
from array_generator import Polygon, UnitCell, Array, rectangle_centered
import numpy as np

# Create custom polygons
poly1 = rectangle_centered(0.0, 20.0, 40.0, 40.0)
poly2 = rectangle_centered(0.0, -20.0, 40.0, 40.0)

# Define unit cell
unit_cell = UnitCell(
    pitch_x=100.0,
    pitch_y=100.0,
    polygons=(poly1, poly2)
)

# Generate array
array = Array(unit_cell=unit_cell, rows=5, cols=5)

# Get all polygons with world coordinates
polygons = array.generate_polygons()
print(f"Generated {len(polygons)} polygons")
```

## Core Concepts

### Coordinate System

- **Unit Cell Origin**: Center of unit cell at (0, 0)
- **Unit Cell Bounds**: [-pitch_x/2, pitch_x/2] × [-pitch_y/2, pitch_y/2]
- **Array Origin**: Bottom-left corner (configurable)
- **Units**: All coordinates in nanometers (nm)

### Canonical Form

Polygons are automatically normalized to canonical form:
- Vertices in counter-clockwise (CCW) order
- First vertex is lexicographically smallest
- No duplicate consecutive vertices

This ensures consistent representation and comparison.

## API Reference

### Core Classes

#### `Polygon`

Immutable polygon representation.

```python
vertices = np.array([[0, 0], [100, 0], [100, 50], [0, 50]], dtype=np.float64)
poly = Polygon(vertices=vertices)

# Methods
bbox = poly.bbox()  # (min_x, min_y, max_x, max_y)
centroid = poly.centroid()  # (cx, cy)
area = poly.area()  # Area in nm²
translated = poly.translate((dx, dy))  # New translated polygon
```

#### `UnitCell`

Unit cell definition for periodic arrays.

```python
unit_cell = UnitCell(
    pitch_x=100.0,
    pitch_y=100.0,
    polygons=(poly1, poly2, ...)
)

# Methods
bounds = unit_cell.bounds()  # (min_x, min_y, max_x, max_y)
n = unit_cell.num_polygons()  # Number of polygons
area = unit_cell.total_area()  # Total polygon area
density = unit_cell.density()  # Feature density (0 to 1)
```

#### `Array`

Periodic array generated by tiling a unit cell.

```python
array = Array(
    unit_cell=unit_cell,
    rows=10,
    cols=10,
    origin=(0.0, 0.0)
)

# Methods
n_cells = array.num_cells()  # Total cells
n_polys = array.num_polygons()  # Total polygons
bounds = array.bounds()  # Array bounding box
center = array.get_cell_center(i, j)  # Cell center coordinates
centers = array.get_all_cell_centers()  # All cell centers
polygons = array.generate_polygons()  # All polygons (list)
vertices = array.generate_polygons_vectorized()  # All vertices (numpy array)
```

### Constructors

#### `rectangle_centered(center_x, center_y, width, height)`

Create axis-aligned rectangle centered at (center_x, center_y).

```python
rect = rectangle_centered(0.0, 0.0, 100.0, 50.0)
```

#### `rectangle_corner(x, y, width, height)`

Create axis-aligned rectangle with bottom-left corner at (x, y).

```python
rect = rectangle_corner(0.0, 0.0, 100.0, 50.0)
```

### Templates

#### `simple_contact_array(cd, pitch, rows, cols, origin=(0, 0))`

Generate simple square contact array (1 contact per cell).

```python
array = simple_contact_array(cd=50.0, pitch=100.0, rows=10, cols=10)
```

#### `staggered_contact_array(cd, pitch_x, pitch_y, rows, cols, stagger_fraction=0.25, origin=(0, 0))`

Generate brick/staggered contact array (2 contacts per cell).

```python
array = staggered_contact_array(
    cd=50.0,
    pitch_x=100.0,
    pitch_y=100.0,
    rows=10,
    cols=10,
    stagger_fraction=0.25
)
```

#### `cluster_contact_array(cd, spacing, pitch, rows, cols, cluster_size=3, origin=(0, 0))`

Generate cluster contact array (N contacts per cell in a row).

```python
array = cluster_contact_array(
    cd=30.0,
    spacing=50.0,
    pitch=200.0,
    rows=5,
    cols=5,
    cluster_size=3
)
```

### Export Functions

#### `export_polygon_vertices(polygons, filename, format='csv')`

Export polygon vertices to text file.

```python
polygons = array.generate_polygons()
export_polygon_vertices(polygons, 'vertices.csv', format='csv')
```

#### `export_polygon_centroids(polygons, filename, format='csv')`

Export polygon centroids to text file.

```python
export_polygon_centroids(polygons, 'centroids.csv', format='csv')
```

#### `export_to_gds(array, filename, layer=1, datatype=0)`

Export array to GDS format.

```python
export_to_gds(array, 'array.gds', layer=1, datatype=0)
```

#### `export_array_metadata(array, filename)`

Export array metadata to text file.

```python
export_array_metadata(array, 'metadata.txt')
```

### Visualization Functions

#### `plot_unit_cell(unit_cell, show_bounds=True, ax=None, title=None)`

Plot unit cell with matplotlib.

```python
plot_unit_cell(array.unit_cell, show_bounds=True)
```

#### `plot_array(array, max_cells=100, show_grid=True, ax=None, title=None)`

Plot array (or subset if too large).

```python
plot_array(array, max_cells=100, show_grid=True)
```

#### `save_unit_cell_plot(unit_cell, filename, show_bounds=True, dpi=150)`

Save unit cell plot to file.

```python
save_unit_cell_plot(array.unit_cell, 'unit_cell.png', dpi=300)
```

#### `save_array_plot(array, filename, max_cells=100, show_grid=True, dpi=150)`

Save array plot to file.

```python
save_array_plot(array, 'array.png', max_cells=100, dpi=300)
```

Use `generate_polygons_vectorized()` for best performance with large arrays.
